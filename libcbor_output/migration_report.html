# Core Model Specifications ### `CborItem.java` - Base abstraction for all CBOR values. - Holds common behavior: type, structural equality, encoded size, serialization dispatch, and container accessors. - Implemented as an abstract `class` because most CBOR values have behavior and nested child relationships during compilation. ### `CborType.java` - Enum representing CBOR major types: - `UNSIGNED_INTEGER` (Major type 0) - `NEGATIVE_INTEGER` (Major type 1) - `BYTE_STRING` (Major type 2) - `TEXT_STRING` (Major type 3) - `ARRAY` (Major type 4) - `MAP` (Major type 5) - `TAG` (Major type 6) - `FLOAT_OR_CTRL` (Major type 7)

cbor/serialization.c (Legacy C serializer dispatch) C 
size_t cbor_serialize(const cbor_item_t* item, unsigned char* buffer,
                      size_t buffer_size) {
  CBOR_ASSERT_VALID_TYPE(cbor_typeof(item));
  switch (cbor_typeof(item)) {
    case CBOR_TYPE_UINT:
      return cbor_serialize_uint(item, buffer, buffer_size);
    case CBOR_TYPE_NEGINT:
      return cbor_serialize_negint(item, buffer, buffer_size);
    case CBOR_TYPE_BYTESTRING:
      return cbor_serialize_bytestring(item, buffer, buffer_size);
    case CBOR_TYPE_STRING:
      return cbor_serialize_string(item, buffer, buffer_size);
    case CBOR_TYPE_ARRAY:
      return cbor_serialize_array(item, buffer, buffer_size);
    case CBOR_TYPE_MAP:
      return cbor_serialize_map(item, buffer, buffer_size);
    case CBOR_TYPE_TAG:
      return cbor_serialize_tag(item, buffer, buffer_size);
    case CBOR_TYPE_FLOAT_CTRL:
      return cbor_serialize_float_ctrl(item, buffer, buffer_size);
    default:
      return 0;
  }
}

# Serialization Components ### `CborSerializer.java` - Performs size calculations and byte stream generation. - Decoupled from core items, converting instances of `CborItem` into raw bytes. - Fully supports definite/indefinite layouts for strings and array/map containers. - Throws checked `CborSerializationException` upon serializing malformed items (e.g. Tag without items).
CborSerializer.java (Migrated Java Serializer) Java 
package com.migration.generated.libcbor.serialization;

import com.migration.generated.libcbor.CborSerializationException;
import com.migration.generated.libcbor.encoding.CborEncoder;
import com.migration.generated.libcbor.model.*;
import java.io.ByteArrayOutputStream;

public final class CborSerializer {
    public static byte[] serialize(CborItem item) {
        ByteArrayOutputStream out = new ByteArrayOutputStream(serializedSize(item));
        write(item, out);
        return out.toByteArray();
    }

    public static int serializedSize(CborItem item) {
        ByteArrayOutputStream out = new ByteArrayOutputStream();
        write(item, out);
        return out.size();
    }

    private static void write(CborItem item, ByteArrayOutputStream out) {
        if (item instanceof CborUnsignedInteger value) {
            writeUnsignedWithWidth(out, 0, value.value(), value.width());
        } else if (item instanceof CborNegativeInteger value) {
            writeUnsignedWithWidth(out, 1, value.encodedMagnitude(), value.width());
        } // ... (rest of implementation follows spec rules)
    }
}

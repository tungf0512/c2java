# libcbor

Single-module Maven project containing a Java translation of the libcbor C library.

Overview:
- This repository provides a Java 17+ translation of libcbor in a clean Maven module.
- No production dependencies are declared in this root project.
- This is a single-module root (no nested modules) with the root pom.xml already present at the repository root.

Build and test:
- Build and run tests with: mvn test

Usage:
- The project is intended to be built and tested via Maven from the repository root.
